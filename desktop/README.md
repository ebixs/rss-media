# داشبورد RSS روی دسکتاپ

- **مک:** [RSS-Dashboard-Mac.zip](https://github.com/ebixs/rss-media/raw/main/desktop/RSS-Dashboard-Mac.zip) — باز کنید، «RSS Dashboard» را به Applications یا Dock بکشید. بار اول: کلیک راست ← Open ← Open.
- **ویندوز:** [RSS-Dashboard-Windows.zip](https://github.com/ebixs/rss-media/raw/main/desktop/RSS-Dashboard-Windows.zip) — همهٔ فایل‌ها را Extract کنید، روی `install.bat` دوبار کلیک کنید. آیکون «RSS Dashboard» روی دسکتاپ ساخته می‌شود.

هر دو فقط نشانی داشبورد زنده را در مرورگر باز می‌کنند. مرورگر باید وارد حساب claude.ai باشد.
